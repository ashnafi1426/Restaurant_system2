TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

PROBLEM: "Command not found" error
─────────────────────────────────
Solution:
  1. php artisan clear-cache
  2. Try again: php artisan seed:delivery-data

PROBLEM: "No waiter found" error
────────────────────────────────
Solution:
  1. php artisan db:seed (run basic seeders first)
  2. Then: php artisan seed:delivery-data

PROBLEM: Page still shows "No assigned orders yet"
──────────────────────────────────────────────
Solution:
  1. Make sure you pressed Ctrl+Shift+R (hard refresh)
  2. Try again: Ctrl+Shift+R
  3. If still empty:
     - Check console (F12) for errors
     - Try again: php artisan seed:delivery-data --fresh
     - Refresh: Ctrl+Shift+R

PROBLEM: Button doesn't appear on order
──────────────────────────────────────
Solution:
  1. Make sure order status is "accepted" or "picked_up"
  2. Look for BLUE or PURPLE status badge
  3. Other statuses (assigned, on_delivery, delivered) don't have the button

PROBLEM: Click button but nothing happens
──────────────────────────────────────
Solution:
  1. Open console: F12
  2. Check for error messages
  3. Copy the error and share it
  4. Most likely causes:
     - 401: Token expired (re-login)
     - 404: Order not found
     - 400: Status not right
     - 500: Server error
