HOW START DELIVERY WORKS:
═════════════════════════════════════════════════════════════════

1. USER CLICKS BUTTON
   ┌─────────────────────────────────┐
   │ [Start Delivery] (green)        │
   └─────────────────────────────────┘
           ↓
2. FRONTEND SENDS REQUEST
   PATCH /waiter/assignments/{id}/start-delivery
   Authorization: Bearer {token}
           ↓
3. BACKEND VALIDATES
   ✓ User authenticated
   ✓ Assignment exists
   ✓ Status is 'accepted' or 'picked_up'
           ↓
4. BACKEND UPDATES
   status: 'accepted' → 'on_delivery'
   on_delivery_at: now()
           ↓
5. BACKEND RETURNS 200 OK
   {
     "success": true,
     "message": "Delivery started successfully",
     "data": {...}
   }
           ↓
6. FRONTEND RELOADS DATA
   ✓ Order status changes to 'on_delivery'
   ✓ Button disappears
   ✓ Console shows: "✅ Delivery started successfully"
